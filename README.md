# Oyun Tanıtım Sitesi

Bu proje, bir oyunun özelliklerini ve detaylarını şık bir arayüzle tanıtmak amacıyla geliştirilmiştir. Modern ve mobil uyumlu bir tasarıma sahiptir.

## 🚀 Özellikler
- **Responsive Tasarım:** Telefon, tablet ve bilgisayarlarda sorunsuz görünüm.
- **Modern Görünüm:** Koyu tema (Dark Mode) estetiği ile göz yormayan arayüz.
- **Hızlı ve Hafif:** Gereksiz yüklerden arındırılmış temiz kod yapısı.

## 🛠️ Kullanılan Teknolojiler
- HTML5
- CSS3 (Flexbox & Responsive tasarım teknikleri)

## 📝 Nasıl Çalıştırılır?
1. Projeyi bilgisayarınıza indirin veya klonlayın.
2. `index.html` dosyasını favori tarayıcınızda açın.
3. VS Code kullanıyorsanız, "Live Server" eklentisi ile canlı olarak önizleme yapabilirsiniz.
